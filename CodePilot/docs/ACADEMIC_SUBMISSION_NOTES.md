# What You Still Need to Personalize for College

The project package contains the software and reusable technical documentation. Before final submission, add the items that only you/your college can provide:

- college title-page format,
- student name(s), roll/register number(s) and section,
- guide/supervisor name and designation,
- department/HOD details,
- bonafide/certificate page and signatures,
- declaration/originality page required by your institution,
- acknowledgement,
- college logo where required,
- final dashboard screenshots from your laptop,
- terminal screenshot of `pytest` and benchmark results,
- Docker/API documentation screenshots if shown in the report,
- final PPT using `PRESENTATION_OUTLINE.md`,
- screen-recorded demo if required,
- weekly project logbook/progress diary if your department uses one,
- team contribution matrix for group projects,
- reference list in your required citation style,
- plagiarism/similarity report if mandated.

Do not claim third-party libraries or research ideas as your own. It is fine for the product itself to be vendor-neutral, but academic citations, dependency licenses and your institution's originality requirements should still be respected.

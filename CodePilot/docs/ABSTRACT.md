# Abstract

**Project:** CodePilot — Autonomous Software Engineering Agent for Repository-Level Bug Resolution

Software bug resolution is a multi-stage engineering process involving defect interpretation, source-code discovery, reproduction, modification, validation, review and delivery. CodePilot automates this pre-merge workflow while retaining a human approval gate. The system accepts a Git repository and natural-language bug report, creates an isolated working copy, performs natural-language triage, indexes source code, retrieves relevant code using vector and lexical ranking, executes baseline tests, applies a constrained repair, re-runs verification tests, reviews the resulting Git diff and creates a pull-request-ready local branch, commit and summary. Specialized triage, retrieval, validation, repair, review and delivery agents coordinate the workflow. A UCB1 reward-learning policy records repair outcomes and ranks available strategies. The application is implemented with React, FastAPI, SQLAlchemy, PostgreSQL/SQLite, Git, Docker and Nginx. A deterministic offline repair mode allows reproducible demonstration without paid external credentials. The included controlled benchmark contains three inclusive-boundary defects; all three were reproduced, repaired, verified and approved by the automated review gate. The project demonstrates NLP, RAG, code embeddings, multi-agent orchestration, reinforcement-learning concepts, automated testing, full-stack development and production-oriented deployment within one auditable software engineering system.

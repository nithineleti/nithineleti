# Demo Script

1. Start `./run_demo.sh` and open `http://localhost:8000`.
2. Add a key using PUT.
3. Read the key and show which node served it.
4. Open `/nodes` and show replicated copies.
5. Take a node down and explain consistent hashing rerouting.

Interview line: "This project helped me understand how distributed storage uses hashing, replication, TTL, and failure handling."

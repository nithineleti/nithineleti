# Demo Script

1. Start `./run_demo.sh` and open `http://localhost:8000`.
2. Create a normal job and a fail-first job.
3. Click **Run Next Job** and explain priority selection.
4. Run again after one second and explain retry recovery.
5. Open `/stats` and explain observability.

Interview line: "This project shows worker coordination, retry strategy, scheduling, and fault handling, which are core backend concepts."

# CodePilot AI - Autonomous Software Engineering Agent

A demo-ready developer tooling project that analyzes a bug report, retrieves relevant code, generates a safe patch, validates it using automated checks, and returns a review-ready code diff.

## Quick Demo

```bash
cd 04_codepilot_ai_autonomous_agent
./run_demo.sh
```

Open `http://localhost:8000` in the browser.

## Run Tests

```bash
pip install -r requirements.txt
pytest -q
```

## Docker Demo

```bash
docker compose up --build
```

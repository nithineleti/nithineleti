# Demo Script

1. Start `./run_demo.sh` and open `http://localhost:8000`.
2. Read the default bug report: divide by zero crash.
3. Click **Analyze Bug Report**.
4. Explain retrieved files, generated diff, validation checks, and review status.
5. Open `/repo/files` to show the indexed sample repository.

Interview line: "I designed this as a developer productivity system with retrieval, patch generation, sandbox-like validation, and review-ready output."

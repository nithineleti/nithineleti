# Demo Script

1. Start the app with `./run_demo.sh`.
2. Open the browser at `http://localhost:8000`.
3. Click **Load Products** and explain database read + cache.
4. Click **Place Demo Order** and explain inventory reservation + idempotency key.
5. Click **Capture Payment** and explain state transition + events.
6. Click **Load Events** and explain asynchronous flow using queues in production.

Interview line: "This project shows how I handle consistency in order workflows using transactions, locks, idempotency, event logs, and cache invalidation."

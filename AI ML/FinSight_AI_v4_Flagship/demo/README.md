# FinSight AI v4 Demo Evidence

This folder contains captured evidence from the bundled offline demo.

- `FinSight_AI_v4_Demo_Overview.png` - command-center view after the flagship workflow.
- `FinSight_AI_v4_Demo_Research.png` - multi-agent trace, grounded summary and ranked evidence.
- `FinSight_AI_v4_Demo_GraphRAG.png` - company-scoped knowledge-graph reasoning view.
- `DEMO_OUTPUT.json` - machine-readable output from `scripts/demo_api.py`.
- `DEMO_CLI_OUTPUT.txt` - terminal trace from the same workflow.
- `Aster_Systems_FinSight_Research.pdf` / `.md` - sample report generated from the captured workflow output.
- `TEST_RESULTS.txt` - latest automated test evidence.

The bundled evaluation set is intentionally small and deterministic for interview demonstrations. Do not present its metrics as external benchmarks.

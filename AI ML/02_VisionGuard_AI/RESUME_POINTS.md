# Resume Points
- Built a computer-vision inspection service that detects surface defects, localizes anomalous regions with bounding boxes, and returns confidence/severity scores through a FastAPI inference API.
- Implemented image preprocessing, region-of-interest analysis, real-time browser visualization, sample inspection workflows, request validation, Docker deployment and automated tests.
- Added pluggable PyTorch/YOLO model adapters so the lightweight local demo can be upgraded to trained deep-learning detection models without changing the API contract.

# RecSysX — Hybrid Recommendation Engine
A reproducible recommender that combines content similarity, user-user collaborative signals and popularity. The UI shows both recommendations and score components.

## Run
`./run.sh` → `http://localhost:8000`.

## Why it is strong for AI/ML resumes
It goes beyond a notebook: feature construction, hybrid ranking, top-K serving, explainability, metrics, API, Docker and tests. Optional `ml/` modules show how to evolve toward a PyTorch two-tower + FAISS retrieval architecture.

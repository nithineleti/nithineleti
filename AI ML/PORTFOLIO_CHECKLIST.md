# AI/ML Portfolio Checklist

Before adding a project to your final resume:
- Run the project from a fresh terminal.
- Run `pytest -q` and save a screenshot of the passing tests.
- Push the repository to GitHub with a clean README and demo preview.
- Deploy at least 2–3 of the five apps publicly.
- Record a 60–90 second demo video for each deployed project.
- Add one architecture diagram and one metric/evaluation table to each GitHub README.
- For optional YOLO/PyTorch/FAISS/MLflow/Airflow paths, execute them before claiming them as trained/deployed experience.
- Be ready to explain data flow, algorithm choice, model metric, failure mode, scaling plan and your exact implementation contribution.
